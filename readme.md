# Diskscan

CLI-утилита которая за один проход собирает подробный отчёт о заполненности
диска Windows и сохраняет его. Программа ничего не удаляет и не изменяет —
только читает.

### Как запустить?

1. Положите `diskscan.exe` в любую папку (например, на рабочий стол).
2. ПКМ по `diskscan.exe` → **Запуск от имени администратора** (без прав часть
   системных папок будет недоступна и отчёт выйдет неполным).
3. Введите букву диска, например `C`, и нажмите Enter.
4. Через несколько минут рядом с программой появится `disk-report-C.md`.

### Использование

```
diskscan [буква_диска] [опции]

Опции:
  -h, --help  Показать эту справку и выйти

Примеры:
  diskscan       Спросит букву диска и соберёт отчёт
  diskscan C     Собрать отчёт по диску C:
  diskscan D:    Собрать отчёт по диску D:
```

### Что попадает в отчёт

| Раздел                      | Содержимое                                                                                                                                                                                          |
|-----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Система                     | ОС, сборка, объём ОЗУ, права администратора                                                                                                                                                         |
| Диск                        | Объём, занято, свободно, ФС; сколько места не удалось учесть (теневые копии, MFT)                                                                                                                   |
| Известные места для очистки | ~80 правил: Temp, кэш Windows Update, WinSxS, Windows.old, hiberfil.sys, кэши браузеров, Discord, Telegram, npm/pip/NuGet/Gradle/Maven, Docker/WSL, Steam, Загрузки… с пометкой, как именно чистить |
| Крупнейшие папки            | Дерево папок от 512 МБ (или 0,5% диска)                                                                                                                                                             |
| Крупнейшие файлы            | Топ-60 с датой изменения                                                                                                                                                                            |
| Типы файлов                 | Топ-30 расширений по объёму                                                                                                                                                                         |
| Установленные программы     | Топ-40 по размеру: из реестра и фактический на диске                                                                                                                                                |
| Недоступные папки           | Что не удалось прочитать                                                                                                                                                                            |
